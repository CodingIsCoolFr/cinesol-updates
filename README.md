# CineSol

A Windows app that finds films and TV episodes across the torrent indexes and streams them.

**[Download CineSol-Setup-0.3.2-win64.exe](https://github.com/CodingIsCoolFr/cinesol-updates/releases/latest/download/CineSol-Setup-0.3.2-win64.exe)** and run it. It installs for you alone, needs no administrator rights, and keeps itself up to date.

This repository holds the downloads and the update feed CineSol checks. The source is private.
